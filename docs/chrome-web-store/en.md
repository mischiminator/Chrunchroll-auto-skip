## Name
Crunchyroll Auto Skip

## Short description
Automatically click Crunchyroll skip buttons for recaps, intros, endings and previews, and close the end screen.

## Full description
Enjoy your anime with fewer clicks.

Crunchyroll Auto Skip automatically clicks available skip buttons on Crunchyroll. Choose which sections to skip and keep watching without reaching for your mouse every time.

WATCH YOUR WAY
• Enable or disable skipping for recaps, intros, endings/credits and next-episode previews individually.
• Turn automatic skipping on or off from the extension popup.
• Choose a delay of 0–10 seconds for intros and endings. Recaps and previews have no added delay.
• Automatically close the recommendations screen when playback ends. You can turn off “End screen” in the popup.
• Want to watch an intro or ending? Press D while its skip button is visible, before the automatic skip happens. You can choose a different single-character key in the settings.
• Use the popup in English, German, Spanish, French or Portuguese (Brazil).
• Your preferences are saved for next time.

GETTING STARTED
Install the extension, refresh your Crunchyroll tab and start watching. Open the extension popup to choose which sections to skip. Under Advanced, you can change the delay, shortcut key and popup language.

HOW SKIPPING WORKS
The extension uses skip buttons provided by Crunchyroll. If an episode has no suitable button, it cannot skip that section. The end screen is closed with its own close button. It does not detect scene boundaries or skip using timestamps. Button availability varies between episodes, and changes to Crunchyroll's player may affect compatibility.

The shortcut works only while a suitable skip button is visible and before skipping happens. The player must have keyboard focus. With a delay of zero seconds, skipping may happen before you can press the key. Turning automatic skipping off cancels a pending countdown.

HELP AND SOURCE CODE
Open Advanced in the extension popup and click GitHub at the bottom to open the project in a new tab. You can find the source code, report problems and suggest improvements there.
