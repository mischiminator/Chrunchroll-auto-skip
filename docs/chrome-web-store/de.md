## Name
Crunchyroll Auto Skip

## Short description
Überspringt Rückblicke, Intros, Abspänne und Vorschauen auf Crunchyroll automatisch und schließt den Endbildschirm.

## Full description
Genieße deine Anime mit weniger Klicks.

Crunchyroll Auto Skip klickt auf Crunchyroll automatisch auf verfügbare Überspringen-Buttons. Entscheide selbst, welche Abschnitte du überspringen möchtest, und schau weiter, ohne jedes Mal zur Maus greifen zu müssen.

SO SCHAUST DU, WIE DU MÖCHTEST
• Aktiviere oder deaktiviere das Überspringen separat für Rückblicke, Intros, Endings/Abspänne und Vorschauen auf die nächste Folge.
• Schalte das automatische Überspringen im Erweiterungs-Popup ein oder aus.
• Wähle für Intros und Abspänne eine Verzögerung von 0–10 Sekunden. Rückblicke und Vorschauen werden ohne zusätzliche Verzögerung übersprungen.
• Schließe den Empfehlungsbildschirm am Ende der Wiedergabe automatisch. Im Popup kannst du „Endbildschirm“ ausschalten.
• Du möchtest ein Intro oder Ending ansehen? Drücke D, solange der Überspringen-Button sichtbar ist und bevor automatisch übersprungen wird. In den Einstellungen kannst du eine andere einzelne Zeichentaste wählen.
• Nutze das Popup auf Deutsch, Englisch, Spanisch, Französisch oder Portugiesisch (Brasilien).
• Deine Einstellungen bleiben für das nächste Mal gespeichert.

SO GEHT'S LOS
Installiere die Erweiterung, lade deinen Crunchyroll-Tab neu und starte die Wiedergabe. Öffne das Erweiterungs-Popup, um die gewünschten Abschnitte auszuwählen. Unter „Erweitert“ kannst du die Verzögerung, die Taste und die Popup-Sprache ändern.

SO FUNKTIONIERT DAS ÜBERSPRINGEN
Die Erweiterung verwendet die von Crunchyroll bereitgestellten Überspringen-Buttons. Fehlt bei einer Folge ein passender Button, kann sie diesen Abschnitt nicht überspringen. Den Endbildschirm schließt sie über dessen eigenen Schließen-Button. Sie erkennt keine Szenengrenzen und überspringt nicht anhand von Zeitstempeln. Die verfügbaren Buttons können je nach Folge variieren. Änderungen am Crunchyroll-Player können die Funktion beeinträchtigen.

Die Taste funktioniert nur, solange ein passender Überspringen-Button sichtbar ist und noch nicht übersprungen wurde. Der Player muss den Tastaturfokus haben. Bei einer Verzögerung von null Sekunden kann das Überspringen erfolgen, bevor du die Taste drücken kannst. Wenn du das automatische Überspringen ausschaltest, wird ein laufender Countdown abgebrochen.
